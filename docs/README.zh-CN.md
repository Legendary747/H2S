# H2S 找房助手

[English](../README.md) · [配置说明（English）](configuration.md) · [配置示例](../config.example.json)

给在荷兰找房的留学生和其他租客提供一点帮助：启用后，在你保持打开的 Holland2Stay 页面中定期刷新、检查可见房源，并通过 Telegram 提醒，让你可以学习、休息或暂时离开屏幕，不必一直守着列表。

这是独立、非官方的浏览器辅助脚本，不保证发现全部房源、及时通知、符合申请资格或预订成功。电脑必须联网、不休眠，并保持浏览器和房源标签页打开；它不是云端监控服务。

> **请先关闭脚本，再进入 H2S。** 正常打开官网并自行完成 Cloudflare 验证或登录后，再到 Tampermonkey（篡改猴）中启用脚本，最后刷新页面。一进入网站就自动运行脚本可能触发验证；这个顺序只是降低干扰的预防措施，不能保证不触发 Cloudflare。结束后请关闭脚本，下次进入官网时仍先正常访问。

## 功能与边界

- 一个或多个城市，可通过 JSON 配置；默认 The Hague、Rijswijk、Rotterdam、Leiden、Zoetermeer。
- 可设置每月**主租金**上限，默认 **€1,000**，不包含 servicekosten、水电等额外支出。
- 可设置运行时段和时区，默认 **Europe/Amsterdam 07:00–23:00**；支持跨午夜时段。
- 完成一轮后，在设定区间内随机刷新，默认 **5–10 分钟**。
- 读取页面已有房源卡片，按需要点击可见的 **Price** 排序和分页；只有确认价格升序时才按预算提前停止翻页。
- Telegram 通知保留成功发送记录并去重；失败待发、限流等待、故障暂停和人工恢复逻辑继续保留。

**请如实理解自动化范围：刷新、排序、翻页、读取页面和通知本身属于自动辅助操作。** 本脚本不提供独立运行的爬虫、直接调用 H2S API 批量采集、自动预订、自动申请、自动付款、验证码破解或 Cloudflare 绕过；也不进入房源详情页或预订页面。它只被动观察网页自身相关请求的响应，以识别验证、限流或接口故障。

使用前请阅读并遵守 [Holland2Stay 条款](https://www.holland2stay.com/terms-and-conditions)。写明“辅助用途”或采用开源许可证，并不等于获得网站许可。没有一种刷新频率能保证不受限制；请保守设置，必要时增大间隔，遇到访问限制就停止，不要试图绕过。

## 安装与启动

1. 在支持的桌面浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。日常使用不需要 Node.js 或 Python。
2. 新建脚本，用 [`h2s-monitor.user.js`](../h2s-monitor.user.js) 的完整内容覆盖并保存。**先在篡改猴中关闭脚本，再访问官网。**
3. 正常进入 [H2S 房源页](https://www.holland2stay.com/residences)，保持官网为**英文界面**，自行完成验证或登录。
4. 在篡改猴中打开脚本，然后刷新页面，确认面板为 **v1.4.0**。
5. 用面板中的目标城市入口打开配置的城市及 **Available to book**。也可手动选择目标城市的子集，或将 City 留空、由脚本本地筛选。无法可靠确认范围的额外官网筛选会被拒绝。
6. 配置 Telegram；如需修改搜索条件，再导入 JSON 配置。同一网站来源只保留一个监控标签页。

脚本启用、页面就绪且处于运行时段时会自动检查；它不会自行打开篡改猴中的开关。时段外可通过“立即检查（允许在夜间手动执行）”手动检查。

**老用户升级：** 直接覆盖原脚本，不要删除后新建、不要同时开两份，也不需要清除历史或强制重发。原脚本名称 `H2S — Den Haag housing monitor`、namespace、存储前缀、Telegram 设置、已保存预算和通知历史均保留；名称中保留 Den Haag 是为了升级兼容，不限制配置其他城市。

## 配置城市、预算和时段

1. 保存并编辑 [`config.example.json`](../config.example.json)。
2. 在脚本空闲时，选择篡改猴菜单 **导入配置 JSON / Import settings JSON**。
3. 粘贴完整 JSON 文件内容。验证成功后保存到本地并刷新；无效配置不会部分覆盖现有设置。
4. **导出配置 JSON / Export settings JSON** 可导出当前搜索设置，不包含 Telegram Token、Chat ID 或通知历史。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | `1` | 配置格式版本 |
| `cities` | 默认五城 | 每个城市包含官网名称 `name` 和筛选 ID `id` |
| `maxRent` | `1000` | 主租金上限，欧元，不含额外费用 |
| `activeHours.start` / `end` | `07:00` / `23:00` | 24 小时制，开始包含、结束不包含；支持跨午夜 |
| `activeHours.timeZone` | `Europe/Amsterdam` | IANA 时区，荷兰夏令时自动随时区处理 |
| `refreshMinutes` | `[5, 10]` | 完整扫描结束后的最短/最长随机刷新分钟数 |

修改城市时，请先在官网选择该城市，从地址中的 `city[filter]=城市名称,ID` 取得真实名称与数字 ID，不要猜。设置保存在 Tampermonkey 本地，脚本不会联网下载 JSON。完整格式和校验要求见[配置说明](configuration.md)。

旧版单独保存的预算会继续沿用；明确导入完整 JSON 后，配置中的预算会成为当前预算。“设置预算（主租金上限）”菜单仍可单独修改预算。脚本不判断房补、学生资格、收入门槛或最终全包费用。

## Telegram 配置

1. 在官方 [@BotFather](https://t.me/BotFather) 创建机器人并取得 Token。
2. 私聊自己的机器人，发送 `/start`。
3. 在 H2S 页面打开篡改猴菜单，选择“配置 Telegram Token”。
4. 选择“自动获取 Chat ID（配对）”，将弹窗的 `h2s-...` 文字原样发给机器人，再确认；也可以手动配置 Chat ID。
5. 点击“测试 Telegram”，确认收到测试消息。

Token 和 Chat ID 只保存在 Tampermonkey；搜索配置导出不含凭据。发送通知时，符合条件的房源信息会发往 Telegram。不要把凭据、账号页面、原始整页 HTML 或浏览器存储导出上传到 Issue。

## 暂停与恢复

| 菜单 | 用途 |
| --- | --- |
| 立即检查（允许在夜间手动执行） | 立刻检查当前范围；不绕过网站限流或验证 |
| 暂停 / 恢复 | 暂停或恢复监控和房源通知 |
| 恢复故障暂停并立即检查 | 修复页面/筛选等问题后，恢复重复失败导致的暂停 |
| 恢复接口暂停（验证完成后） | 自行解决验证或拒绝访问后确认恢复；仍遵守等待时间 |
| 查看历史 | 查看最近本地房源和通知记录 |
| 清除历史并重建基线（不通知现有房源） | 仅在需要重建基线时使用，正常升级无需操作 |
| 重新通知当前符合条件的房源（强制重发） | 主动要求重发，正常扫描无需操作 |

遇到 Cloudflare 请先停用脚本并自行处理，恢复正常访问后再启用。没有通知时先测 Telegram，再查看面板中的时段、筛选、预算、排序与暂停原因。网页变化、加载过慢、后台限速、休眠或网络中断都可能影响检查；两次扫描间出现又消失的房源可能漏掉，Telegram 响应丢失也可能造成重发。
