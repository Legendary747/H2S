# v1.4.0 — Configurable housing search assistance

H2S can now be configured for a reusable housing-search workflow while retaining existing monitoring and notification behavior.

## Changes

- Add locally imported/exported JSON search settings: one or more cities, base-rent budget, active hours/time zone, and refresh interval.
- Keep the default five-city search, €1,000 base-rent limit, 07:00–23:00 Europe/Amsterdam window, and 5–10 minute refresh interval.
- Support minute-level and overnight active windows, with validation before applying imported settings.
- Preserve the userscript identity, Telegram configuration, existing rent budget, notification history, pause state, and network cooldowns during normal upgrades.
- Add an English main README, Chinese guide, configuration guide, contribution/security notes, and MIT license for project-authored material.
- Add GitHub Actions offline tests on Node.js 22 and 24, with a real workflow status badge and an explicitly gated release job that runs only after tests pass.
- Replace historical copied page extracts with minimal synthetic fixtures and invented listing names/URLs, while retaining regression-relevant values and selectors.
- Archive older readmes and the historical v1.3.5 browser-test report rather than presenting them as current evidence.

## Upgrade

Replace the complete contents of the existing Tampermonkey script with [`h2s-monitor.user.js`](https://github.com/Legendary747/H2S/blob/v1.4.0/h2s-monitor.user.js) from this release. Do not create a second enabled copy or clear history for a normal upgrade. Search settings are optional; use [`config.example.json`](https://github.com/Legendary747/H2S/blob/v1.4.0/config.example.json) and the **Import settings JSON** menu to customize them.

**Keep the script disabled before initially opening H2S.** Visit the website normally, complete verification yourself, then enable the script in Tampermonkey and refresh. Automatic activation on first load can contribute to Cloudflare challenges; this sequence is only a precaution.

## Verification and scope

The release uses the Node/linkedom offline regression suite and JavaScript syntax checking. CI runs with Node.js 22 and 24. Tests mock the website, time, navigation, locks, and Telegram; they do not access the live site or send real messages. They are not live H2S/Tampermonkey end-to-end acceptance. Consult the linked Actions run for the exact passing test count and commit.

The script automatically refreshes and interacts with visible sorting/pagination controls. It does not provide a standalone crawler, H2S API harvesting, automatic booking/application/payment, CAPTCHA solving, or Cloudflare bypass. Read the setup guide and website terms before using it.
